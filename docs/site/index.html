The 60-second version

  • Run it: double-click Start Here (Mac).command or Start Here (Windows).bat, pick an input and an output folder, press Run.
  • Read it: open cohort_report.html in the output folder.
  • Analyse it: master_everything.csv — one wide row per recording, 163 columns, including why each channel caused rejections.
  • Change it: everything lives in config/config.yaml, or tick it in the GUI.

The one caveat to remember: this pilot establishes reliability and consistency, not absolute accuracy — no simultaneous research-grade EEG reference was recorded.
